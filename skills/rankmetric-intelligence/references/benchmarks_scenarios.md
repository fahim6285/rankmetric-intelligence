# Benchmarking and target-gap modelling

Benchmark against peer/target values only when scope, methodology edition, reporting period, source quality and denominator are comparable. Distinguish official score, descriptive input, user-defined aspiration, and simulated scenario. Cite the benchmark source and dated edition.

For simple non-scoring targets: `absolute_gap=max(0,target-current)`, `signed_change=target-current`, `relative_change=(target-current)/abs(current)` only when current != 0; explain units. For official weighted scores, obtain applicable official weights, caps, normalisation rules and eligibility conditions; do not linearize a nonlinear formula.

Run sensitivity across explicitly stated assumptions; annotate input version, variance, uncertainty and limit of inference. Do not promise any rank/score movement from unverified model inputs.

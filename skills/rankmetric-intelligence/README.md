# RankMetric Intelligence by Fahim

Open-source, general-purpose plugin skill for institution-level ranking intelligence, bibliometric reconciliation, evidence tracking and metrics quality assurance. The plugin contains no organization's identity, datasets or result history.

**Package structure:** `SKILL.md`, configuration guidance, eight reference protocols, CSV templates, three standalone Python utilities, synthetic example files and a repeatable test script.

**Using the package:** Open the registered plugin in ChatGPT and describe the ranking/evidence task. Attach documents and indicate the applicable reporting period. The agent should consult official applicable rules and retain a provenance trail. For offline local runs, the bundled Python scripts use the standard library; invoke `python scripts/<script>.py --help`.

**Boundaries:** CV production belongs with VitaMorph; manuscripts with R&A; laboratory/scientific computation with SciForge; recruitment with CareerBridge.

**Safety:** No private organizational records or actual university names are shipped inside. All examples are synthetic. Rankings and eligibility are edition-specific and require contemporaneous primary-source verification.

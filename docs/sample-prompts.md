# Sample prompts for RankMetric Intelligence

Copy any prompt, attach your own source files and adjust the details.

1. Reconcile these two publication tables and report every mismatch with its source.
2. Consolidate these SDG-tagged CSV files and remove duplicates by DOI.
3. Build an evidence register for this ranking submission and flag missing items.
4. Map our year-wise metrics to the definitions in the latest official methodology.
5. Run a scenario: how many more indexed publications close the gap to this benchmark?
6. Prepare an indicator report with a full provenance trail.

Tip: attach the official source (posting, syllabus, methodology or CV) and say the exact output format you want. The agent works best when it can cite what you provided.
